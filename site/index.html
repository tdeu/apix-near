Coding agents can build a whole NEAR app from one prompt. The people using them usually can't check whether that code is safe.

APIX adds wallet login, tokens and agent payments to your app, checks any NEAR app for the mistakes that lose funds, and publishes the result on-chain where anyone can check it.

This app was written on purpose with the mistakes coding agents often make.

Three commands, one loop

Each stage works on its own. Together they take an app from first line to launch with a record of what was checked.

Build

Add working NEAR features to a Next.js app. Users sign with their own wallet; the app never holds their keys.

  • apix add wallet: wallet login with NEAR Connect
  • apix near token create: a NEP-141 token on a locked account, so no one can mint more
  • apix add agent-wallet: an AI agent pays through a vault with limits, never with a raw key
$ apix add token --chain near
✅ NEAR token added (3 files written)
   + lib/near/token.ts
   + app/api/token/route.ts
   + components/near/TokenPanel.tsx
🔎 Verified: the project passes 7 code checks.

Verify

Check any NEAR app, whether APIX, an agent or a person wrote it. Twelve rules on the code and on the chain, each with a fix in plain words.

$ apix verify
FAIL Secret exposed to the browser
     NEXT_PUBLIC_NEAR_PRIVATE_KEY is copied into
     the JavaScript every visitor downloads.
FAIL Anyone on the internet can make this
     route spend  app/api/pay/route.ts
FAIL An AI model can spend with no on-chain
     limit  lib/agent.ts
WARN Mainnet is hardcoded in code that spends

Prove

Publish the report's hash and verdict on NEAR, in a contract with no access keys. Nobody can edit the record, and anyone can check a report against it.

$ apix attest --account you.testnet
✅ Attested: FAIL (7 failures, 3 warnings)
$ apix attestation you.testnet my-app \
    --report apix-report.json
✓ matches the on-chain attestation.

What the vault enforces

Checked by the contract on every payment

  • Each payment and each day stays under the owner's limits
  • Only allowlisted accounts can be paid
  • Bigger payments wait for the owner's approval
  • The owner can pause the vault or revoke the agent's key at once
  • The agent's key can't change any of this: NEAR rejects it before the contract runs

Run it yourself

Node.js 22.12 or newer. The first two checks need no account and no keys. The testnet script creates its own free accounts with the NEAR faucet and runs the whole loop on-chain in about five minutes.

APIX started as a Hedera tool and won the Hedera Africa Hackathon in 2025. Everything NEAR was built for NEAR HACKATHON in November 2026, and the repository shows exactly what changed.

Read the README · See every testnet transaction

$ git clone https://github.com/tdeu/apix-near
$ cd apix-near && npm ci && npm run build

# an unsafe app, then one APIX built
$ node dist/cli/index.js verify examples/unsafe-tip-agent --offline
$ node dist/cli/index.js verify examples/agent-shop --offline

# the full loop on NEAR testnet
$ scripts/near-testnet-demo.sh
